Support

Help for install issues, sync problems, widgets, Apple Watch, and support questions.

Use this page when QuitGentle is not behaving as expected, when Cloud Sync looks wrong between devices, or when you need help with exports, permissions, widgets, or the Apple Watch companion.

Common help topics

  • Install or update issues
  • Cloud Sync across iPhone and iPad
  • Import and export questions
  • Apple Health / HealthKit heart-rate attachment behavior
  • Location permission or hotspot-map behavior
  • Widget availability or refresh behavior
  • Apple Watch syncing and complication refresh
  • Bug reports or general support questions

What to include in a report

  • Device model
  • iOS version and watchOS version, if relevant
  • QuitGentle version and build number
  • What you expected
  • What happened instead

If Cloud Sync is involved, include screenshots of the Today screen’s Sync Status card on each device if possible.

Current public support channel

Email support@quitgentle.com for install issues, Cloud Sync problems, widget or Apple Watch bugs, and other support questions. You can also use the structured GitHub support form when a report needs screenshots, device details, or step-by-step bug context.

For privacy-specific questions, email privacy@quitgentle.com. A GitHub account is currently required to submit the structured support form.

If this is urgent

QuitGentle is a self-management companion, not emergency support. If someone needs urgent help, use local emergency services or immediate smoking-cessation support options.
